# Problema y objetivos

La suplantación de identidad puede afectar trámites notariales. NotaryVerify evalúa si combinar factores reduce escenarios controlados de suplantación frente al uso de un solo factor.

El objetivo de solución es desarrollar y validar un prototipo que use solamente identidades ficticias y biometría de voluntarios con consentimiento. El proyecto debe registrar sesiones, factores, resultados, responsable y decisión; medir escenarios legítimos y de ataque; y mantener trazabilidad entre requisitos y pruebas. Las fuentes detalladas son el [README raíz](../../../README.md) y el [SRS histórico](../../academica/indice.md).
