# Actores y roles

| Actor | Responsabilidad |
| --- | --- |
| Operador | Ejecuta verificaciones y consulta sus resultados. |
| Administrador | Registra consentimiento, identidades ficticias, fotos de referencia y credenciales. |
| Auditor | Consulta sesiones y verifica la cadena de auditoría. |
| Participante voluntario | Aporta datos biométricos autorizados asociados a una identidad ficticia. |
| Simuladores | Representan identidad y SID-Sunarp sin acceso institucional real. |

La aplicación actual no implementa todavía una autenticación/autorización completa; el control de acceso por roles permanece como requisito de evolución documentado.
