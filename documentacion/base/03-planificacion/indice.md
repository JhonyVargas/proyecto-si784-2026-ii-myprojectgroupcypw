# Planificación ejecutable

GitHub es el sistema maestro de ejecución: cada cambio se desarrolla desde una
issue con milestone, prioridad, área, fase, dependencias, criterios de
aceptación, pruebas y Definition of Done. Esta carpeta conserva la trazabilidad
académica y enlaza los identificadores reales, sin duplicar el cuerpo de issues.

- [Roadmap](roadmap.md): ocho milestones y resultados demostrables.
- [Backlog](backlog.md): issues ejecutables, estado real y clasificación.
- [Fases](fases.md): MVP, V1, evaluación, cierre y posterior.
- [Orden y ruta crítica](desglose-tareas.md): secuencia, blockers y trabajo paralelo.
- [Matriz de trazabilidad](trazabilidad.md): RF, RNF y RN hacia issues, módulos,
  pruebas y evidencia.

GitHub Project no se configuró: el token actual no dispone de `read:project`.
Issues + Milestones ofrecen el flujo suficiente sin duplicar campos ni bloquear
el desarrollo.
