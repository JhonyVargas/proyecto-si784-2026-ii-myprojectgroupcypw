# Roadmap

1. Bootstrap profesional: estructura, documentación, operación reproducible y trazabilidad.
2. Estabilización MVP: completar y verificar flujos y pruebas existentes.
3. Evaluación controlada: 100 intentos biométricos y métricas de aceptación/rechazo.
4. Endurecimiento académico: roles, fallos de simuladores y revisión de seguridad.
5. Entrega: evidencias, defectos críticos cerrados y trazabilidad prioritaria.
