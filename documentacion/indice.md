# Documentación de NotaryVerify

Este es el índice canónico del prototipo académico de verificación multicapa de identidad para trámites notariales simulados. El sistema no sustituye a Reniec, SID-Sunarp, la firma digital oficial ni la identificación legal.

## Navegación

- [Contexto](base/00-contexto/indice.md): visión, problema, objetivos y alcance.
- [Funcional](base/01-funcional/indice.md): actores, requisitos, casos de uso y reglas.
- [Arquitectura](base/02-arquitectura/indice.md): componentes, datos, API y decisiones.
- [Planificación](base/03-planificacion/indice.md): MVP, fases, backlog y tareas.
- [Calidad y operación](base/04-calidad-operacion/indice.md): pruebas, seguridad, ejecución y convenciones.
- [Fuentes académicas](academica/indice.md): informes conservados y su trazabilidad.

Las decisiones futuras se identifican expresamente como **pendientes**. El README raíz resume el proyecto y [AGENTS.md](../AGENTS.md) indica cómo colaborar.
