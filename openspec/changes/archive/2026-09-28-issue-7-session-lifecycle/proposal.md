# Proposal

## Why

Las sesiones requerían responsable autenticado, expiración recuperable e
historial filtrable para completar RF-08/RF-18 y RN-10.

## What Changes

- Materializar expiración al operar o consultar y exponer historial administrativo filtrable.

## Capabilities

### New Capabilities
- `verification-session-lifecycle`: vigencia e historial seguro de sesiones.

### Modified Capabilities
- Ninguna.

## Impact

Servicio y API de verificaciones, esquemas, pruebas y documentación.
